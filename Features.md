# PLate.Launcher — Features

Comprehensive overview of all desktop, multitasking, customization, and power user features in **PLate.Launcher**.

---

## 🖥️ Desktop & Multitasking

- **Accessibility Overlay Mode**: Runs as a lightweight system overlay without requiring default launcher replacement, or functions as a full home screen launcher.
- **Desktop Task View**: Full-screen overview of active apps with keyboard navigation and one-tap RAM cleanup.
- **Alt-Tab HUD Switcher**: Instant keyboard and gesture application switching (`Alt+Tab`, `Ctrl+Tab`, `Alt+<` / `Alt+>`).
- **Flexible Dock Layouts**: Centered floating dock (KDE-style) or edge-pinned taskbar (Windows-style) with 3 one-tap presets (Minimal, Default, Gesture).
- **Floating & Tiled Windows**: Resizable freeform app windows with snap-to-edge window tiling (maximize, split left/right, top/bottom).
- **Dock Window Grouping**: Multiple instances and tasks group cleanly under a single dock icon.
- **Hot Corners**: Configurable top-right and bottom-right corner trigger zones mapped to custom navigation actions.
- **Multi-Display Ready**: Native secondary screen and external monitor desktop presentations.
- **Hardware Input**: Full right-click context menus, mouse pointer capture, and hardware keyboard shortcuts.
- **Inline Calculator**: Instant math calculations directly inside the app search bar (e.g., type `12+7` → get `19`).

---

## ⚡ Power & Session Menu

- **System Power Controls**: Lock, power off, restart, and quick access to system settings.
- **Isolated Restart**: Restart or terminate PLate.Launcher independently without affecting the Android OS or open background tasks.
- **Multi-User Switching**: Switch between device profiles directly from the dock power menu.

---

## 📱 Apps & App Drawer

- **App Drawer**: Searchable, alphabetized drawer with category filtering and app hiding.
- **App Shortcuts**: Long-press app icons to trigger native Android deep shortcuts.
- **Icon Packs**: Compatible with third-party launcher icon packs.
- **Per-App Launch Modes**: Remembers windowed or fullscreen preference on a per-application basis.
- **Orientation Lock**: Optional forced landscape mode for desktop monitor workflows.

---

## 📊 Taskbar & System Tray

- **Task Manager**: Minimize, restore, and close running apps directly from dock indicators.
- **Live System Monitors**: Real-time CPU load, available RAM, and network indicators.
- **Status Tray**: Battery percentage, Wi-Fi status, Bluetooth controls, volume slider, and system clock.
- **Notification Panel**: Interactive notification center with per-app notification silencing.
- **Quick Settings**: Slide-out panel for brightness, volume, and quick hardware toggles.

---

## 🎨 Live Wallpaper Engine

- **High-Performance Video Engine**: Smooth video playback rendered natively via OpenGL ES or Vulkan.
- **Interactive Editor**: Crop, rotate, zoom, pan, and adjust brightness, contrast, and saturation with multi-touch gestures.
- **Dual-Profile Orientation**: Completely independent wallpaper scaling, cropping, and audio speed settings for portrait and landscape.
- **Desktop Grid**: Customizable icon grid with smart icon collision avoidance and widget placement.

---

## 🛍️ Workshop & Extensions

- **Wallpaper & Font Browser**: In-app repository browser with built-in ad-blocking.
- **Automatic Font Capture**: Automatically grabs and installs fonts directly from web sources like Google Fonts without manual downloads.
- **Curated Catalogues**: Pre-configured feeds (MotionBGs, MoeWalls, DaFont, Fontesk) plus support for custom RSS/API sources.
- **Plugin System**: Installs and manages modular plugin ZIPs and Magisk-style modules with runtime on/off toggles.

---

## ⚙️ Customization & Personalization

- **Material You & Custom Colors**: Dynamic theme color extraction, custom dock bubble colors, and full transparency modes.
- **Dual-Font Typography**: Assign distinct custom fonts for Latin and Arabic scripts simultaneously.
- **Custom UI Audio**: Personalized audio effects for screen lock, unlock, low battery, and system alerts.
- **DPI & Scale Tuning**: System-wide or per-application font and icon scaling.

---

## 🛡️ Root & Shizuku Integration

- **One-Shot Auto-Grant**: Batch grants over 20 advanced system permissions in a single command.
- **Resolution Control**: Change display size, resolution, and forced DPI on the fly.
- **Process Management**: Freeze background processes and manage system packages.
- **Built-in Shell Terminal**: Execute privileged root or Shizuku shell commands directly from the launcher.
- **QA Self-Test Suite**: Headless sandbox activity runner on an isolated virtual display to diagnose app stability.
