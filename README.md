## ⚡ Highlights

- **Desktop Overlay & Launcher**: Runs as an overlay via Accessibility Service or as your default launcher.
- **Window Multitasking**: Resizable floating windows with snap tiling (maximize, split left/right/top/bottom).
- **Task View & Alt-Tab**: Full-screen overview of active apps with instant keyboard switching and RAM clearing.
- **Customizable Dock**: Floating or pinned dock with real-time CPU/RAM monitors and customizable presets.
- **Live Wallpaper Engine**: Hardware-accelerated OpenGL ES and Vulkan video wallpaper engine with gesture controls.
- **In-App Workshop**: Download wallpapers and fonts with built-in ad-blocking and automatic font capture.

## 🚀 Quick Start

1. Download and install the latest APK from [GitHub Releases](https://github.com/Zoro-15/PLate.Dex/releases).
2. Enable the **Accessibility Service** when prompted during first launch.
3. Launch desktop mode from your home screen, Quick Settings tile, or desktop shortcut.

*For complete setup options including Shizuku, Root, and ADB permissions, see [Guide.md](Guide.md).*
